# Prediction Lab

An experimental platform for building and **honestly evaluating** predictive systems.

The first benchmark domain is the French Loto, used as a *negative control*: a correctly
operated lottery should be unpredictable from past draws alone. The goal is not to predict
it. The goal is to build a system that can tell the difference between signal and noise —
and that is allowed to conclude "no statistically meaningful predictive signal was detected".

See `docs/STATUS.md` for what currently works.
